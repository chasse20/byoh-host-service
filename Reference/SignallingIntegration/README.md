# Pixel Streaming Reference

The original project integrated with Epic Games' Unreal Engine Pixel Streaming Signalling Web Server. The vendored Epic implementation and associated web assets/platform scripts are intentionally omitted from this public portfolio copy.

`BYOH.js` is retained because it is the project-specific integration module that connected the signalling
layer to the host/scaling service. It is provided as historical reference code and is not a standalone server.
